# Hotel Management System

A simple, modular Java console application built to manage hotel room reservations, food orders, and checkout bills. 

Developed by **NAZMUL AMIN**.

---

## Features

- **Room Management:** Handle bookings for single and double rooms with availability tracking.
- **Food Service:** Order meals directly to rooms with automated price totals.
- **Invoice Billing:** Generate simple checkout bills combining room charges and food orders.
- **Clean Structure:** Separated into distinct classes for easy maintenance.

---

## Project Structure

```text
Hotel_management_system/
└── src/
    ├── Main.java           # Program entry point and user interaction
    ├── HotelService.java   # Core logic for handling bookings and billing
    ├── Room.java           # Room model
    └── FoodItem.java       # Food menu model
```

---

## How to Run

### Prerequisites
Make sure you have Java (JDK 8 or later) installed on your system.

### Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nazmulaminnahin/Hotel_management_system.git
   ```

2. **Navigate to the source directory:**
   ```bash
   cd Hotel_management_system/src
   ```

3. **Compile the files:**
   ```bash
   javac *.java
   ```

4. **Run the program:**
   ```bash
   java Main
   ```
